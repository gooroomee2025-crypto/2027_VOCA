# 2027 S/S VOCA

심슨보카 Day 01~10(500단어)을 매일 50단어씩 학습하고, 4지선다형 퀴즈로 실력을 점검하는 반응형 웹 MVP입니다. 별도 빌드 도구 없이 순수 HTML/CSS/JS로 만들어져 있어 정적 파일 그대로 호스팅하면 바로 동작하고, 이후 PWA(설치형 모바일 앱)로 확장하기 쉬운 구조입니다.

## 실행 방법

**로컬에서 미리보기**
정적 파일이므로 아래처럼 폴더를 그대로 로컬 서버로 띄우면 됩니다. (`index.html`을 더블클릭해서 열어도 대부분 동작하지만, 서비스워커 캐싱 기능은 `http(s)` 환경에서만 정상 등록됩니다.)

```bash
npx serve .
# 또는
python3 -m http.server 8000
```

**배포**
`index.html`, `style.css`, `app.js`, `data.js`, `manifest.json`, `sw.js` 6개 파일을 같은 폴더 구조로 유지한 채 Netlify, Vercel, GitHub Pages, Cloudflare Pages 등 정적 호스팅에 그대로 올리면 됩니다. HTTPS 환경에 배포하면 각 브라우저의 "홈 화면에 추가" 기능으로 PWA처럼 설치할 수 있습니다.

## 파일 구조

```
index.html    앱 셸(상단바 + 하단 탭 내비게이션 + 뷰 컨테이너)
style.css     디자인 토큰 + 전체 스타일 (모바일 우선 반응형)
app.js        상태관리 · 라우팅 · 화면 렌더링 로직 (프레임워크 없는 vanilla JS)
data.js       엑셀에서 추출한 500단어 데이터 (Day/No/단어/뜻/어원 메모)
manifest.json PWA 매니페스트 (앱 이름, 아이콘, 테마 컬러)
sw.js         서비스워커 — 앱 셸 오프라인 캐싱 기본 골격
```

## 화면 구성

| 경로 | 내용 |
|---|---|
| `#/` | 홈 — 오늘 Day의 학습 진행률(스티치 게이지), 연속 학습일, 퀴즈 최고점, 단어 학습/퀴즈 CTA |
| `#/words` | Day별 50단어 플래시카드 — 탭하면 뜻/어원 메모 공개, 아는 단어·모르는 단어 체크, 즐겨찾기, 미니 그리드로 단어 점프 |
| `#/quiz` | Day 선택 → 문항 수 선택(10/20/50) → 4지선다 퀴즈 진행 → 결과 및 문항별 리뷰 |
| `#/notes` | 오답노트(퀴즈에서 틀린 단어 자동 저장) / 즐겨찾기 탭 |
| `#/settings` | 진행률·퀴즈기록·오답노트·즐겨찾기 개별 초기화, 전체 데이터 초기화 |

## 데이터 저장 방식

모든 학습 기록(진행률, 퀴즈 점수, 오답노트, 즐겨찾기, 연속 학습일)은 `localStorage`의 `voca2027_state_v1` 키 하나에 JSON으로 저장됩니다. 서버 없이 기기 안에서만 유지되며, 브라우저 데이터를 지우면 초기화됩니다.

## 향후 모바일 앱(PWA) 확장 포인트

- **아이콘 교체**: 현재 `manifest.json`의 아이콘은 임시 SVG data URI입니다. 실제 배포 전 192×192 / 512×512 PNG 아이콘으로 교체를 권장합니다.
- **서비스워커 고도화**: `sw.js`는 앱 셸 캐싱만 구현된 기본 골격입니다. 오프라인 큐잉, 백그라운드 동기화 등은 필요에 따라 추가하세요.
- **알림**: 매일 학습 리마인드 푸시는 Web Push API + 별도 서버(또는 OneSignal 등)가 필요합니다.
- **계정/동기화**: 지금은 기기 로컬 저장뿐이라 기기를 바꾸면 기록이 사라집니다. 여러 기기 동기화가 필요하면 백엔드(예: Supabase, Firebase)를 붙여 `localStorage` 대신 원격 저장으로 교체하면 되도록 `app.js`의 `loadState()/saveState()` 두 함수에 저장 로직이 모여 있습니다.
- **Day 11 이상 확장**: `data.js`의 `VOCAB_DATA` 배열에 동일한 형식(`{id, day, no, word, meaning, memo}`)으로 이어서 추가하면 자동으로 Day 선택 칩과 학습/퀴즈에 반영됩니다.
